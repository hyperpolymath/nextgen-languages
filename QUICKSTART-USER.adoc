== What this repository is

`nextgen-languages` is a research portfolio and coordination hub, not a language runtime, installer, compiler, or unified product. The languages and related projects are maintained independently.

== Find a project

1. Read link:README.adoc[the README] for the front door.
2. Open link:languages/README.adoc[the language index] to choose a canonical project.
3. Use link:docs/ecosystem-map.adoc[the ecosystem map] to distinguish core languages from syntax surfaces, tools, shared substrates, curricula, and neighboring research.
4. Check the selected project's own README, roadmap, and evidence before adopting it; portfolio inclusion is not a readiness recommendation.

== Installation

There is nothing to install to browse this repository. To install a language or language tool, follow instructions in its canonical repository. This coordinator does not provide an all-language package or setup command.
