== Solo

____
Dependable foundation for systems programming
____

*Status:* 📝 Placeholder - contributions welcome

=== Overview

Solo is the foundational text-based language in the my-lang family,
designed for ages 8-10 as their first transition from visual to
text-based programming.

=== Core Invariant

*Effects are always explicit—no hidden side effects.*

=== Key Features

* `+effect { ... }+` - Explicit effect tracking
* `+go { ... }+` - Structured concurrency
* `+where { pre: ..., post: ... }+` - Design-by-contract

=== Example

[source,solo]
----
fn greet(name: String) -> String
  effect { console }
  where { pre: name.length > 0 }
{
  console.print("Hello, ")
  console.print(name)
  return "greeted"
}
----

=== Getting Started

[source,bash]
----
cd my-lang
cargo run --bin solo
----
