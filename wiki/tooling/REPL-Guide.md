# REPL Guide: A General Orientation

A read–eval–print loop is an interactive interface some languages provide. No shared REPL or `nextgen` command is supplied by this portfolio, and a REPL's absence does not imply that a language lacks a usable implementation.

Check the language repository for a documented command, supported syntax, state-reset behavior, and limitations. Do not run sample syntax from one language in another project's REPL. Start from the [language index](../../languages/README.adoc) and follow its canonical links.
