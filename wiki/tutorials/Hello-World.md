# Your First Program

This portfolio does not publish one verified “Hello, World!” program that works across its independent languages. Earlier cross-language examples were illustrative placeholders and are intentionally not reproduced here as executable claims.

To run a real first program:

1. Choose a project from [the language index](../../languages/README.adoc).
2. Follow its canonical repository's quick start and toolchain requirements.
3. Use an example and command maintained by that project.
4. If you discover that its quick start is missing or broken, report that issue to the owning repository rather than copying unverified syntax into this coordinator.

For selection help, read [[Choosing-a-Language]].
