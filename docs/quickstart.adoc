= Quick Start — Next-Generation Languages Coordinator
:toc:

This file previously contained an unverified FormBD/VeriSimDB development plan, machine-specific paths, and commands for repositories and tools that are not part of this coordinator. That material is withdrawn as an operational guide; this replacement prevents the stale filename from continuing to direct contributors to it.

== For this coordinator

Read link:../README.adoc[README] for navigation and link:../EXPLAINME.adoc[EXPLAINME] for architecture and scope. To work on this repository, use link:../QUICKSTART-DEV.adoc[the contributor quick start].

This repository has no compiler build, language runtime, package artifact, or service to install. Its substantive checks are:

[source,bash]
----
bash hooks/validate-language-registry.sh
bash hooks/validate-coordinator-boundary.sh
git diff --check
----

== For an individual language

Choose a canonical project from link:../languages/README.adoc[the language index] and follow its own current README, roadmap, and test instructions. Do not use a coordinator-level recipe as a substitute for the language project's build or proof evidence.

== For ecosystem relationships

Use link:ecosystem-map.adoc[the ecosystem map] to distinguish core languages from syntax surfaces, shared substrates, tools, curricula, and adjacent research. A link indicates discoverability unless a tested dependency or integration is explicitly evidenced.
