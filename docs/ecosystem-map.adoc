== 4. Tools and teaching layer

=== Language augmentation (`*-iser`) tools

The estate includes tools such as link:https://github.com/hyperpolymath/affinescriptiser[affinescriptiser], link:https://github.com/hyperpolymath/anvomidaviser[anvomidaviser], link:https://github.com/hyperpolymath/betlangiser[betlangiser], link:https://github.com/hyperpolymath/eclexiaiser[eclexiaiser], link:https://github.com/hyperpolymath/ephapaxiser[ephapaxiser], link:https://github.com/hyperpolymath/mylangiser[mylangiser], link:https://github.com/hyperpolymath/phronesiser[phronesiser], and link:https://github.com/hyperpolymath/wokelangiser[wokelangiser].

These aim to apply selected language-derived ideas to other codebases. An `-iser` is a separate tool with its own maturity and evidence; it is not a compiler for the parent language and its existence does not imply production readiness.

=== Education and presentation

* link:https://github.com/hyperpolymath/tentacles-agentic-syllabus[tentacles-agentic-syllabus] is a curriculum/agentic teaching framework, not a language implementation. It uses My-Lang dialects as one learning vehicle; “Me” is a generated projection, not a dialect.
* link:https://github.com/hyperpolymath/nextgen-language-evangeliser[nextgen-language-evangeliser] is an educational toolkit, not a language or shared compiler.
* link:https://github.com/metadatastician/berrywiki[BerryWiki] (Metadatastician estate) is an optional notebook-style authoring/navigation tool. The portfolio wiki remains plain Markdown in this repository; the tool is not a content dependency or canonical language source.
* Per-language examples and lessons belong with each language's canonical repository unless that repository explicitly delegates them elsewhere.

== 5. Adjacent estates and project naming

This coordinator is not the registry for the database or type-theory estates. `TOOLING-STATUS.adoc` names selected adjacent projects (including the KRL resolution stack and TypeLL) where those distinctions matter. Keep estate ownership and canonical project status with their own registries.

JtV is indexed here under canonical `hyperpolymath/jtv`. A separate public `hyperpolymath/jtv-lang` repository describes related JtV research. Its exact lineage and canonical status have not been confirmed by this coordinator; treat it as a *lineage question*, not as a second member or a confirmed alias, until the project owner reconciles the repositories.

The public repositories `hyperpolymath/ziz` and `hyperpolymath/Ziz` could not be resolved on 2026-09-26, and public estate search did not identify a matching language project. “Ziz” therefore remains an unresolved name only; no registry entry or wiki project page is fabricated. For a private or differently named project, its owner must provide the canonical URL and visibility-safe description.
