== Language Quick Reference

Each language has one core invariant that defines its design philosophy.

[width="100%",cols="48%,52%",options="header",]
|===
|Language |Invariant
|link:my-lang.adoc[my-lang] |Each level builds exactly on the previous

|link:phronesis.adoc[phronesis] |Every AI decision traces to declared
values

|link:eclexia.adoc[eclexia] |No computation without explicit resource
budget

|link:oblibeny.adoc[oblibeny] |All programs must provably terminate

|link:anvomidav.adoc[anvomidav] |Every deadline is statically guaranteed

|link:wokelang.adoc[wokelang] |No operation without explicit consent

|link:betlang.adoc[betlang] |All uncertainty must be explicitly modeled

|link:jtv.adoc[jtv] |Data and code are strictly separated

|link:affinescript.adoc[affinescript] |Every resource is used at most once

|link:ephapax.adoc[ephapax] |Every value can be consumed exactly once

|link:haec.adoc[haec] |Every quality-loss is graded and checked against
its use

|link:error-lang.adoc[error-lang] |Errors are first-class: systems
thinking taught through failure

|link:tangle.adoc[tangle] |Programs are braids; equivalence is topological
isotopy

|link:007.adoc[007] |Agents that make agents (private repo, anti-scrape;
index-only)

|link:kitchenspeak.adoc[kitchenspeak] |Physical-process constraints are
enforced in the types

|link:firmboot.adoc[firmboot] |Admitted changes preserve declared
continuity obligations (research prototype)
|===

Each row links to a thin pointer; the language itself lives in its own
`+hyperpolymath/<lang>+` repo. For cross-language status see
link:../TOOLING-STATUS.adoc[`+../TOOLING-STATUS.adoc+`],
link:../.machine_readable/LANGUAGES.a2ml[`+../.machine_readable/LANGUAGES.a2ml+`],
and
link:../language-status-tracker.jl[`+../language-status-tracker.jl+`].
