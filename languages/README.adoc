== Related but not additional core languages

The AffineScript syntax surfaces (CafeScripto, JaffaScript, LucidScript, PseudoScript, and RattleScript), Kategoria, Panoply, typed-wasm, echo-types, `*-iser` tools, and teaching projects are mapped separately in link:../docs/ecosystem-map.adoc[the ecosystem map]. Keeping these categories separate prevents a tool, surface, substrate, or curriculum from being mistaken for another core language.

For evidence and cross-language status, see link:../TOOLING-STATUS.adoc[`TOOLING-STATUS.adoc`], link:../.machine_readable/LANGUAGES.a2ml[the registry], and the dated link:../docs/audits/2026-09-07-language-portfolio.md[portfolio audit].
