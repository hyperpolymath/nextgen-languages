= nextgen-languages — Coordinator Maintenance Guide
:toc:
:toclevels: 2

== Scope

This repository is a pure coordinator; it has no runtime service, language compiler build, distributable binary, or installable application. Do not package or deploy it as if it were a language implementation. The language repositories own their own release and packaging processes.

== Dependencies and checks

For the coordinator checks, Bash and Git are sufficient. `just` provides convenience recipes. Guix users can enter the declared environment with `guix shell -m manifest.scm`.

[source,bash]
----
bash hooks/validate-language-registry.sh
bash hooks/validate-coordinator-boundary.sh
git diff --check
----

== Registry maintenance

The registry scope is `.machine_readable/LANGUAGES.a2ml`; `languages/*.adoc` provides the corresponding human pointers. A committed family member must be reflected consistently in the registry, boundary guard, ecosystem metadata, and tracker. Validate the full set with `bash hooks/validate-language-registry.sh`.

Do not add an adjacent tool, syntax surface, curriculum, library, or research lab as a core language merely for discoverability. Add those to `docs/ecosystem-map.adoc` with their relationship category. Confirm the canonical repository and its privacy policy before publishing a pointer.

== Releases and operational deployment

There is no release artifact or service to deploy from this coordinator. Changes are reviewed and merged through the repository's normal GitHub process. Check the owning project repository for language or tool releases.
